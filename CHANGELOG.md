# Изменения

## 1.1.0

- Первый публичный установщик для текущего пользователя Windows.
- Собственный ярлык StudioFix на рабочем столе и в меню «Пуск».
- Обычный ярлык TikTok LIVE Studio открывает саму Studio. Подключение лаунчера к нему удалено; сохранённые подключения прежних тестовых сборок можно восстановить.
- Проверка обновлений приложения и правил из публичных GitHub Releases.
- Уведомление о новой версии, загрузка и запуск установщика по кнопке.
- Проверка подписи RSA/SHA-256 и контрольной суммы установщика; отказ от перехода на старую версию.
- Поиск Studio через реестр, ярлыки, стандартные папки и расширенный поиск; ручной ввод папки, EXE или ярлыка.
- Компактное тёмное окно, векторные иконки Lucide, резервная копия перед правкой и отдельная кнопка запуска.
