# Проверка публичной сборки 1.1.0

Локальные проверки выполнены 2026-10-15 на Windows x64 с установленным .NET Framework 4.8. Это отчёт о выполненных проверках, а не подтверждение совместимости со всеми компьютерами и версиями Studio.

- Применение, повторная проверка и точный откат правил для оригинальных `main.js` 1.36.6 и 1.37.4; хэши совпали с каталогом. Для запуска использовался отдельный тестовый EXE.
- Отказ от правки запущенной Studio и от применения по устаревшей контрольной сумме.
- Неподдерживаемая версия запускается без изменения тестового файла.
- Сохранённый путь следует за активной папкой установщика Studio; ручной ввод EXE, ярлыка и внутреннего файла распознаётся.
- Подписанные правила загружаются через имитацию HTTPS-ответов GitHub; изменённая подпись, устаревший каталог и перенаправление вне разрешённых адресов отклоняются. Проверенный кэш работает без сети.
- Подписанное обновление приложения предлагает только новую версию. Подмена подписи, другая версия Release, другой репозиторий, неверный хэш и слишком большой установщик отклоняются.
- Настоящее WPF-окно: применение правки, отдельный запуск, статус установленного фикса, запуск без фикса с откатом, запуск неподдерживаемой копии. Ручной ввод пути с пробелами и кириллицей проверен через Windows UI Automation.
- Установщик: установка в отдельную тестовую папку, собственные ярлыки, запуск установленного EXE, повторная установка с сохранением данных и удаление. Общий ярлык TikTok LIVE Studio не изменился.
- Восстановление записанных подключений старой тестовой сборки проверено на временных ярлыках. Изменённый вручную ярлык сохраняется.
- Главное окно и окно обновления отрендерены и просмотрены: [главное окно](preview.png), [макет уведомления](update-preview.png). Версия 1.2.0 на втором изображении — тестовый пример интерфейса, а не опубликованный релиз.

Исходники проверок: [LauncherTests.cs](../tests/LauncherTests.cs), [AppUpdatesTests.cs](../tests/AppUpdatesTests.cs), [Verify-Installer.ps1](../tests/Verify-Installer.ps1). Оригинальные файлы TikTok и ключ подписания не включены в репозиторий.

Успешные реальные эфиры после правок подтверждены пользователем в ходе подготовки проекта. Новые версии Studio требуют отдельной проверки эфира; имитация ответов сервера и запуск тестового EXE такую проверку не заменяют.
